# RigReady-Backend
RigReady API es el motor de cálculo de la plataforma. Recibe el hardware del usuario, lo cruza matemáticamente con los requisitos de videojuegos mediante algoritmos y benchmarks, determina compatibilidad (Mínimo/Recomendado/Ultra), ajusta por factor de forma (Desktop/Laptop), detecta cuellos de botella CPU-GPU y devuelve un veredicto preciso.
